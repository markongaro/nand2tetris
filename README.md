# DESCRIPTION
This repository is about building a general-purpose computer system - hardware and software - from the ground up.
Beginning from a NAND gate only, the project involves building a hadware platform that entails a CPU, RAM, datapath,
and a software hierarchy.
The sofware aspect include:
a. An assembler
b. Virtual machine
c. A Basic OS
d. A compiler.
